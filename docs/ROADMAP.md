# Roadmap

## 1.0 CLI estable

- SDK oficial local sin Android Studio.
- AVD oficial con system images del Android Emulator.
- Comandos para diagnosticar, instalar, crear, iniciar, detener, reparar, limpiar cache, ver logs e instalar APKs.
- Configuracion simple en JSON.
- Separacion de sistema, instancias, logs, descargas, backups y perfiles.

## 1.1 Perfiles gamer

- Perfiles por juego o app.
- Presets de RAM, cores, resolucion y densidad.
- Arranque rapido por perfil.
- Plantillas en `runtime/profiles`.

## 1.2 Keymapping

- Mapeo de teclado/mouse a input Android.
- Perfiles de controles por app.
- Import/export de configuraciones.

## 1.3 GUI macOS

- Interfaz grafica nativa o ligera para usuarios finales.
- Botones para instalar SDK, crear instancia, iniciar, detener e instalar APK.
- Visualizacion de estado, logs y dispositivos.

## 1.4 Updater

- Actualizacion guiada de SDK/emulator/system images.
- Verificacion de versiones disponibles.
- Backups antes de cambios riesgosos.

## 2.0 Windows/Linux

- Soporte multiplataforma.
- Imagen ABI adecuada por arquitectura.
- Instaladores por sistema operativo.
- Adaptadores de rutas, permisos y virtualizacion.
